# 수업 은행 (Lesson Bank)

원장이 매주 **이번 주 수업 계획**을 만들 때 여기서 수업을 꺼내 쓴다. 학생 상태에 맞게 순서를 바꾸거나, 쉬운 버전으로 쪼개거나, 같은 수업을 다시 넣어도 된다.

- 수업 번호: `P1-01`처럼 단계(Phase)와 순서로 부른다. P1 = 1단계(가나 읽기 + 인사·자기소개), P2 = 2단계(기초 문형).
- 3단계 이후 수업은 로드맵(`roadmap.md`)의 주제를 보고 원장이 그 시기에 새로 만들어 여기에 추가한다.
- 각 수업: **주제 / 새 글자(있으면) / 핵심 표현 / 읽기 / 쓰기 / 롤플레이**
- 핵심 표현 3개 중 가나 글자는 행 단위로 숙달을 추적한다(예: "あ행 (あいうえお)").
- 표기: 1~4묶음(1~4주차)은 한국어 발음을 붙이고, 5묶음부터는 한자에 후리가나만 단다.
- 읽기 소재는 그날까지 배운 글자로만 만든다. 핵심 표현에 아직 안 배운 글자가 있으면 소리로만 익힌다.

### P1 · 1묶음 · 히라가나 1 (청음 전반) + 첫 인사 · 1주차
- **P1-01 · あ행·か행 + 아침 인사** / 새 글자: あいうえお かきくけこ / あ행 (あいうえお) · か행 (かきくけこ) · おはようございます (오하요- 고자이마스) [정중체] → 반말 おはよう (오하요-) / 읽기: 글자 10개 → あい(사랑)·いえ(집)·かお(얼굴)·えき(역)·あかい(빨갛다) → 문장 「あかい いえ」 / 쓰기(로마자 OK): "얼굴", "역", "빨간 집" / 롤플레이: 아침에 유키와 인사하기(おはよう와 おはようございます의 차이)
- **P1-02 · さ행·た행 + 처음 만났을 때** / 새 글자: さしすせそ たちつてと (し·ち·つ 소리 주의) / さ행 (さしすせそ) · た행 (たちつてと) · はじめまして (하지메마시테) [정중체·반말] / 읽기: すし(초밥)·あさ(아침)·くつ(신발)·ちかてつ(지하철)·おいしい(맛있다) → 「おいしい すし」 / 쓰기(로마자 OK): すし, ちかてつ, おいしい すし / 롤플레이: 유키를 처음 만나 인사하기
- **P1-03 · な행·は행 + 잘 부탁해요** / 새 글자: なにぬねの はひふへほ (조사 は는 "와") / な행 (なにぬねの) · は행 (はひふへほ) · よろしく おねがいします (요로시쿠 오네가이시마스) [정중체] → 반말 よろしく (요로시쿠) / 읽기: ねこ(고양이)·いぬ(개)·はな(꽃)·ひと(사람)·ふね(배)·ほし(별) → 「ねこと いぬ」 / 쓰기(로마자 OK): ねこ, はな, ひと / 롤플레이: はじめまして → よろしく 주고받기
- **P1-04 · ま행·や행 + 이름 말하기** / 새 글자: まみむめも やゆよ / ま행 (まみむめも) · や행 (やゆよ) · わたしは ~です (와타시와 ~데스) [정중체] → 반말 ~だよ (~다요) / 읽기: やま(산)·うみ(바다)·ゆき(눈)·もも(복숭아)·みせ(가게)·むすめ(딸) → 「やまと うみ」 / 쓰기(로마자 OK): やま, ゆき, "저는 (내 이름)입니다" / 롤플레이: 유키에게 이름 말하고 유키 이름 묻기

### P1 · 2묶음 · 히라가나 2 (나머지·탁음·요음) + 나라·직업 · 2주차
- **P1-05 · ら행·わ·を·ん + 나라 말하기** / 새 글자: らりるれろ わ を ん (を는 "오") / ら행 (らりるれろ) · わ·を·ん · かんこくじんです (캉코쿠진데스) [정중체] → 반말 かんこくじんだよ (캉코쿠진다요) / 읽기: さくら(벚꽃)·くるま(차)·はる(봄)·ほん(책)·わたし(나)·にほん(일본) → 「ほんを よむ」 / 쓰기(로마자 OK): さくら, にほん, わたしは かんこくじんです / 롤플레이: 어느 나라 사람인지 묻고 답하기
- **P1-06 · 탁음·반탁음 + 괜찮아요** / 새 글자: が ざ だ ば행(점 두 개) · ぱ행(동그라미) / が행·ざ행 (がぎぐげご·ざじずぜぞ) · だ행·ば행·ぱ행 · だいじょうぶです (다이죠-부데스) [정중체] → 반말 だいじょうぶ (다이죠-부) / 읽기: かぎ(열쇠)·かぜ(바람)·でんわ(전화)·ぶた(돼지)·てんぷら(튀김)·えんぴつ(연필) → 「てんぷらを たべる」 / 쓰기(로마자 OK): でんわ, てんぷら, だいじょうぶです / 롤플레이: 유키와 부딪혔을 때 すみません ↔ だいじょうぶです
- **P1-07 · 요음·작은 っ·장음 + 직업 말하기** / 새 글자: きゃ·しゅ·ちょ 등 요음, 작은 っ(한 박 쉬기), 장음(おかあさん·とうきょう) / 요음 (きゃ·しゅ·ちょ 등) · 작은 っ과 장음 · かいしゃいんです (카이샤인데스) [정중체] → 반말 かいしゃいんだよ (카이샤인다요) / 읽기: きって(우표)·がっこう(학교)·しゃしん(사진)·とうきょう(도쿄)·りょこう(여행) → 「とうきょうへ りょこう」(へ는 "에") / 쓰기(로마자 OK): りょこう, とうきょう, かいしゃいんです / 롤플레이: 직업 묻고 답하기(おしごとは? → かいしゃいんです)
- **P1-08 · 히라가나 총복습 + 이름 묻기** / 헷갈리는 히라가나 짝 (さ/ち, ぬ/め, は/ほ, れ/わ/ね) · おなまえは なんですか (오나마에와 난데스카) [정중체] → 반말 なまえは? (나마에와?) · ~と もうします (~토 모-시마스) [비즈니스 경어] → 정중체 ~です / 읽기: 유키의 히라가나 자기소개 4문장 / 쓰기: 내 자기소개 3문장(로마자 OK) + 다음 주부터 쓸 휴대폰 일본어 자판 추가(아이폰: 설정 → 일반 → 키보드 → 새로운 키보드 추가 → 일본어 → 로마자 / 안드로이드: Gboard 설정 → 언어 → 일본어) / 롤플레이: 이름 묻고 답하며 1분 자기소개 주고받기

### P1 · 3묶음 · 가타카나 + 여행 첫 표현 · 3주차 (쓰기는 가나 자판)
- **P1-09 · ア~タ행 + 주문하기** / 새 글자: アイウエオ カキクケコ サシスセソ タチツテト, 장음 ー / ア행·カ행 · サ행·タ행 · コーヒーを ください (코-히-오 쿠다사이) [정중체] → 반말 コーヒー ちょうだい (코-히- 쵸-다이, 친한 사이) / 읽기: アイス·ケーキ·スキー·タクシー·テスト·チケット → 「アイスと ケーキ」 / 쓰기(가나 자판 첫날): アイス, タクシー, コーヒーを ください / 롤플레이: 카페에서 주문하기(점원 역)
- **P1-10 · ナ~ヤ행 + 어디예요?** / 새 글자: ナニヌネノ ハヒフヘホ マミムメモ ヤユヨ / ナ행·ハ행 · マ행·ヤ행 · トイレは どこですか (토이레와 도코데스카) [정중체] → 반말 トイレ どこ? (토이레 도코?) / 읽기: コーヒー·メニュー·ナイフ·ハム·マスク·ノート → 「メニューを ください」 / 쓰기: メニュー, ナイフ, トイレは どこですか / 롤플레이: 호텔·역에서 화장실 위치 묻기(あそこです 알아듣기)
- **P1-11 · ラ·ワ·ン + 탁음·작은 글자 + 있어요?** / 새 글자: ラリルレロ ワヲン, ガ·ザ·ダ·バ·パ행, 작은 ァィゥェォ(ファ·ティ 같은 외래어 소리) / ラ행·ワ·ン · 가타카나 탁음·반탁음·작은 글자 · ~は ありますか (~와 아리마스카) [정중체] → 반말 ~ ある? (~ 아루?) / 읽기: ホテル·ラーメン·バス·ビール·ジュース·コンビニ·カフェ → 「ビールは ありますか」 / 쓰기: ラーメン, コンビニ, 내 이름을 가타카나로 / 롤플레이: 편의점에서 물건이 있는지 묻기
- **P1-12 · 가타카나 총복습 + 이건 뭐예요?** / 헷갈리는 가타카나 짝 (シ/ツ, ソ/ン, ク/ケ/タ, ウ/ワ) · これは なんですか (코레와 난데스카) [정중체] → 반말 これ なに? (코레 나니?) · ~を おねがいします (~오 오네가이시마스) [정중체] → 반말 ~ おねがい (~ 오네가이) / 읽기: 카페 메뉴판(가타카나+히라가나, 가격 포함) / 쓰기: 메뉴에서 2개 골라 주문 문장(ホットコーヒーと ケーキを おねがいします) / 롤플레이: 카페 주문(1~3주 표현 섞기)

### P1 · 4묶음 · 가나 섞어 읽기 + 생활 인사 · 4주차
- **P1-13 · 하루 인사 + 수고했어요** / こんばんは (곰방와) [정중체·반말] · おやすみなさい (오야스미나사이) [정중체] → 반말 おやすみ (오야스미) · おつかれさまです (오츠카레사마데스) [정중체, 직장에서 많이 씀] → 반말 おつかれ (오츠카레) / 읽기: 유키와의 메시지 대화 5줄(가나 섞기) / 쓰기: 유키에게 저녁 인사 메시지 2문장 / 롤플레이: 아침·저녁·잘 때·퇴근할 때 인사 고르기
- **P1-14 · 좋아하는 것과 취미** / ~が すきです (~가 스키데스) [정중체] → 반말 ~が すき (~가 스키) · しゅみは ~です (슈미와 ~데스) [정중체] → 반말 しゅみは ~だよ (슈미와 ~다요) · なにが すきですか (나니가 스키데스카) [정중체] → 반말 なにが すき? (나니가 스키?) / 읽기: 유키의 SNS 자기소개(アニメ·カラオケ·りょこう) / 쓰기: 내 취미 2문장 / 롤플레이: 서로 좋아하는 것 묻고 답하기
- **P1-15 · 맞장구와 다시 묻기** / そうですか (소-데스카) [정중체] → 반말 そうなんだ (소-난다) · もう いちど おねがいします (모- 이치도 오네가이시마스) [정중체] → 반말 もう いっかい (모- 익카이) · ゆっくり おねがいします (윳쿠리 오네가이시마스) [정중체] → 반말 ゆっくり いって (윳쿠리 잇테) / 읽기: 다시 묻는 장면 대화 / 쓰기: "죄송해요, 한 번 더 부탁해요." / 롤플레이: 유키가 일부러 빨리 말하면 다시 묻기
- **P1-16 · 4주 복습** / 1~4주에 학습중인 표현·가나 행 중 약한 것 / 읽기: 가나 섞인 6문장 자기소개 글 / 쓰기: 내 자기소개 5문장(가나 자판) / 롤플레이: 1~4주 표현을 섞은 3분 대화(처음 만남 → 자기소개 → 취미 → 헤어지기)

### P1 · 5묶음 · 한자 첫걸음과 자기소개 실전 · 5주차 (한국어 발음 없음, 후리가나만)
- **P1-17 · 한자 첫걸음: 나라와 사람** / 새 한자: 日本(にほん)·韓国(かんこく)·人(じん/ひと)·私(わたし) / 私(わたし)は 韓国人(かんこくじん)です [정중체] → 반말 韓国人だよ · 日本(にほん)は はじめてです [정중체] → 반말 日本は はじめて · 韓国(かんこく)から 来(き)ました [정중체] → 반말 韓国から 来たよ / 읽기: 유키가 한국 친구를 소개하는 짧은 글 / 쓰기: 私は 韓国人です。日本は はじめてです。 / 롤플레이: 공항·호텔에서 어디서 왔는지 답하기
- **P1-18 · 업무 자기소개 맛보기** / (회사)の (이름)と 申(もう)します [비즈니스 경어] → 정중체 (회사)の (이름)です · よろしく お願(ねが)いいたします [비즈니스 경어] → 정중체 よろしく お願いします · お世話(せわ)に なっております [비즈니스 경어, 메일·전화 첫인사] → 정중체 こんにちは / 읽기: 업무 메일 첫 줄 3개 / 쓰기: 내 업무 자기소개 2문장 / 롤플레이: 거래처 담당자 사토(가상 인물)와 명함 교환하며 인사
- **P1-19 · 헤어질 때와 다음 약속** / 気(き)を つけて [반말] → 정중체 お気を つけて · また 会(あ)いましょう [정중체] → 반말 また 会おう · 楽(たの)しかったです [정중체] → 반말 楽しかった / 읽기: 헤어지는 장면 대화 / 쓰기: 유키에게 "오늘 즐거웠어요. 또 만나요." 메시지 / 롤플레이: 만남을 끝내고 헤어지기
- **P1-20 · 칭찬과 감사** / すごいですね [정중체] → 반말 すごい! · おいしいです [정중체] → 반말 おいしい! · 本当(ほんとう)に ありがとうございました [정중체, 끝난 일에 감사] → 반말 本当に ありがとう / 읽기: 식당 후기 3문장 / 쓰기: 유키에게 감사 메시지 / 롤플레이: 유키 집에 초대받아 음식 칭찬하기

### P1 · 6묶음 · 1단계 정리 · 6주차
- **P1-21 · 묻는 말 기본** / 何(なん)ですか · どこですか · だれですか [정중체] → 반말 なに? · どこ? · だれ? / 읽기: 묻고 답하기 6줄 / 쓰기: 유키에게 질문 3개 / 롤플레이: 유키에게 질문하며 알아가기
- **P1-22 · 여행 외래어 30개** / 약한 가타카나 행 · チェックイン·タクシー·ホテル 등 여행 외래어 · ~まで お願いします [정중체] → 반말 ~まで / 읽기: 역·호텔 안내판 단어 / 쓰기: 여행 외래어 5개 / 롤플레이: 택시 타고 호텔 이름 말하기
- **P1-23 · 처음 만남 대화 전체** / 학습중 표현 중 약한 것 3개 / 읽기: 처음 만난 두 사람의 대화 8줄 / 쓰기: 내 자기소개 6문장(인사·이름·나라·직업·취미·마무리) / 롤플레이: 5분 처음 만남 대화
- **P1-24 · 1단계 총복습 + 진급 점검** / 자주 틀린 가나·표현 / 읽기: 가나 무작위 20자 + 외래어 10개(진급 기준) / 쓰기: 자기소개 3문장 가나 입력 / 롤플레이: 30초 자기소개 → 유키의 질문 3개

### P2 · 1묶음 · です・ます 기본
- **P2-01 · ~は ~です / ~じゃ ありません** / 私は 学生(がくせい)じゃ ありません。 · 会社員(かいしゃいん)ですか。 · はい、そうです。/ いいえ、ちがいます。 / 읽기: 세 사람 소개 글 / 쓰기: 내가 아닌 것 2개 / 롤플레이: 유키가 잘못 알고 있는 것 고쳐주기
- **P2-02 · これ・それ・あれ** / これは 何(なん)ですか。 · それは 私の かさです。 · あれは 駅(えき)です。 / 읽기: 방 안 물건 설명 / 쓰기: 주변 물건 3개 설명 / 롤플레이: 가게에서 물건 가리키며 묻기
- **P2-03 · ここ・そこ・あそこ・どこ** / トイレは どこですか。 · あそこです。 · 駅は この 近(ちか)くですか。 / 읽기: 역 안내 / 쓰기: 위치 묻는 문장 2개 / 롤플레이: 역에서 위치 묻기
- **P2-04 · ~の (소유·소속)** / 私の 名前(なまえ)は ~です。 · 物流(ぶつりゅう)会社の 社員(しゃいん)です。 · だれの ですか。 / 읽기: 소지품 이야기 / 쓰기: 회사·가족 소개 / 롤플레이: 분실물 주인 찾기
- **P2-05 · 동사 ます형 1 (가다·오다·돌아가다)** / 東京(とうきょう)へ 行(い)きます。 · 家(いえ)に 帰(かえ)ります。 · 友(とも)だちが 来(き)ます。 / 읽기: 주말 계획 / 쓰기: 내일 갈 곳 2문장 / 롤플레이: 어디 가는지 묻기

### P2 · 2묶음 · 조사 を・に・が・で
- **P2-06 · ~を ~ます / ~ません** / ご飯(はん)を 食(た)べます。 · コーヒーを 飲(の)みます。 · テレビは 見(み)ません。 / 읽기: 아침 습관 / 쓰기: 먹는 것·안 먹는 것 / 롤플레이: 좋아하는 음식 이야기
- **P2-07 · ~に (장소·대상)** / 日本に 行きます。 · 友だちに 会(あ)います。 · 母(はは)に 電話(でんわ)します。 / 읽기: 주말 일기 / 쓰기: 만날 사람·갈 곳 / 롤플레이: 주말에 누구를 만나는지 묻기
- **P2-08 · ~が あります / います** / 近くに コンビニが あります。 · 犬(いぬ)が います。 · Wi-Fiは ありますか。 / 읽기: 호텔 시설 안내 / 쓰기: 우리 동네 소개 2문장 / 롤플레이: 호텔에 무엇이 있는지 묻기
- **P2-09 · ~が すき・わかる・じょうず** / 日本語(にほんご)が 少(すこ)し わかります。 · ラーメンが すきです。 · 料理(りょうり)が じょうずですね。 / 읽기: 친구 소개 / 쓰기: 할 줄 아는 것·좋아하는 것 / 롤플레이: 서로의 취향 묻기
- **P2-10 · ~で (장소·수단)** / 電車(でんしゃ)で 行きます。 · カフェで 勉強(べんきょう)します。 · カードで いいですか。 / 읽기: 출근길 이야기 / 쓰기: 출근 방법 / 롤플레이: 카드 결제가 되는지 묻기

### P2 · 3묶음 · 숫자와 가격
- **P2-11 · 숫자 1~100** / いち・に・さん … じゅう · 4(よん)·7(なな)·9(きゅう) 읽기 주의 · 何番(なんばん)ですか。 / 읽기: 번호표·좌석 번호 / 쓰기: 숫자 받아쓰기 / 롤플레이: 유키가 말하는 번호 받아 적기(듣기 집중)
- **P2-12 · 가격** / いくらですか。 · 1,500円(せんごひゃくえん)です。 · ちょっと 高(たか)いですね。 / 읽기: 가격표 / 쓰기: 가격 묻고 답하기 / 롤플레이: 기념품 가게 계산
- **P2-13 · 개수 세기** / ひとつ・ふたつ・みっつ … とお · ~を ふたつ ください。 · 全部(ぜんぶ)で いくらですか。 / 읽기: 주문서 / 쓰기: 주문 2문장 / 롤플레이: 빵집에서 개수 말하며 주문
- **P2-14 · 전화번호와 큰 숫자** / 電話番号(でんわばんごう)は ~です。 · 百(ひゃく)・千(せん)・万(まん) · もう 一度(いちど) お願いします。 / 읽기: 예약 확인 문자 / 쓰기: 내 번호 말하기 / 롤플레이: 전화로 번호 받아 적고 확인하기
- **P2-15 · 숫자 복습 + 쇼핑** / 3묶음 표현 / 읽기: 마트 전단지 / 쓰기: 쇼핑 목록과 가격 / 롤플레이: 3분 쇼핑 대화

### P2 · 4묶음 · 시간·요일·날짜
- **P2-16 · 시간** / 今(いま) 何時(なんじ)ですか。 · 3時半(さんじはん)です。 · 4時(よじ)·9時(くじ) 읽기 주의 / 읽기: 전철 시간표 / 쓰기: 하루 일정과 시간 / 롤플레이: 출발 시간 묻기
- **P2-17 · 요일과 어제·오늘·내일** / 月曜日(げつようび)~日曜日(にちようび) · 今日(きょう)・明日(あした)・昨日(きのう) · 何曜日(なんようび)ですか。 / 읽기: 일주일 일정 / 쓰기: 이번 주 계획 / 롤플레이: 약속 요일 정하기
- **P2-18 · 날짜** / ~月(がつ) ~日(にち) · 1日(ついたち)~10日(とおか) 특수 읽기 · 誕生日(たんじょうび)は いつですか。 / 읽기: 행사 안내 / 쓰기: 생일·여행 날짜 / 롤플레이: 예약 날짜 말하기
- **P2-19 · ~から ~まで** / 9時から 6時までです。 · 東京から 大阪(おおさか)まで · 何時までですか。 / 읽기: 영업시간 안내 / 쓰기: 내 근무 시간 / 롤플레이: 가게 영업시간 묻기
- **P2-20 · 예약하기** / 予約(よやく)を お願いします。 · ~人(にん)です。 · ~日の ~時に お願いします。 / 읽기: 예약 확인 메일 / 쓰기: 예약 요청 2문장 / 롤플레이: 식당 전화 예약

### P2 · 5묶음 · 형용사와 과거·권유
- **P2-21 · い형용사** / この ラーメンは おいしいです。 · 高(たか)くないです。 · 安(やす)い ホテル / 읽기: 식당 비교 / 쓰기: 음식 감상 2문장 / 롤플레이: 음식 맛 이야기
- **P2-22 · な형용사** / きれいな 町(まち)ですね。 · 静(しず)かじゃ ないです。 · 有名(ゆうめい)な お寺(てら) / 읽기: 관광지 소개 / 쓰기: 우리 동네 설명 / 롤플레이: 여행지 추천 받기
- **P2-23 · ~ました / ~ませんでした** / 昨日 映画(えいが)を 見ました。 · 朝(あさ)ご飯を 食べませんでした。 · 楽(たの)しかったです。 / 읽기: 여행 일기 / 쓰기: 어제 한 일 3문장 / 롤플레이: 주말에 한 일 묻기
- **P2-24 · ~ませんか / ~ましょう (권유)** / 一緒(いっしょ)に 行きませんか。 · いいですね。行きましょう。 · すみません、ちょっと…。 / 읽기: 초대 메시지 / 쓰기: 유키를 초대하는 메시지 / 롤플레이: 약속 잡기와 정중하게 거절하기
- **P2-25 · 형용사·과거 복습** / 5묶음 표현 / 읽기: 여행 후기 / 쓰기: 다녀온 곳 소개 4문장 / 롤플레이: 여행 다녀온 이야기 3분

### P2 · 6묶음 · 2단계 정리
- **P2-26 · ~も・~と** / 私も 行きます。 · 友だちと 行きます。 · コーヒーと ケーキを お願いします。 / 읽기: 동행 이야기 / 쓰기: 누구와 무엇을 하는지 / 롤플레이: 같이 갈 사람 정하기
- **P2-27 · 묻는 말 정리** / 何・だれ・どこ・いつ・いくら・どうして / 읽기: 인터뷰 묻고 답하기 / 쓰기: 유키 인터뷰 질문 5개 / 롤플레이: 유키 인터뷰하기
- **P2-28 · 하루 일과 말하기** / 毎朝(まいあさ) ~時に 起きます。 · それから ~ます。 · 夜(よる)は ~ます。 / 읽기: 유키의 하루 / 쓰기: 내 하루 5문장(진급 기준) / 롤플레이: 서로의 하루 묻기
- **P2-29 · 짧은 업무 메시지 맛보기** / お世話に なっております。 [비즈니스 경어] · ~の 件(けん)ですが、 [비즈니스 경어] · よろしく お願いいたします。 [비즈니스 경어] / 읽기: 짧은 업무 메일 / 쓰기: 회의 시간 확인 메시지 3문장 / 롤플레이: 사토 씨에게 전화로 시간 확인
- **P2-30 · 2단계 총복습 + 진급 점검** / 내가 자주 틀린 표현 / 읽기: 10주 동안 나온 글 중 하나 / 쓰기: 3문장 메시지 10분 안에(진급 기준) / 롤플레이: 숫자·시간 받아 적기 10개 + 자유 대화 후 레벨 점검과 다음 단계 제안

2단계가 끝나면 학생의 약한 영역과 목적(여행·업무·시험)을 기준으로 3단계 수업을 만들어 여기에 추가한다.

## 부록 · 여행·생활 생존 표현 (복습용)

복습 단계에서 매일 1~2개씩 골라 묻는다. 1~4주차에는 한국어 발음을 같이 보여준다.

**인사**
- こんにちは (곤니치와) [정중체·반말] — 낮 인사. は는 "와"로 읽는다.
- ありがとうございます (아리가토- 고자이마스) [정중체] → 반말 ありがとう (아리가토-)
- すみません (스미마셍) [정중체] — 죄송합니다 / 저기요. → 반말 ごめん (고멘, 사과할 때)
- じゃあ、また (쟈-, 마타) [반말] → 정중체 では、また (데와, 마타)

**대답**
- はい / いいえ (하이 / 이-에) [정중체] → 반말 うん / ううん (응 / 우응)
- だいじょうぶです (다이죠-부데스) [정중체] → 반말 だいじょうぶ
- わかりました (와카리마시타) [정중체] → 반말 わかった (와캇타) → 비즈니스 경어 かしこまりました (카시코마리마시타)

**못 알아들었을 때**
- もう いちど おねがいします (모- 이치도 오네가이시마스) [정중체] → 반말 もう いっかい
- ゆっくり おねがいします (윳쿠리 오네가이시마스) [정중체]
- にほんごが すこし わかります (니홍고가 스코시 와카리마스) [정중체] — 일본어를 조금 알아요.
- えいごは だいじょうぶですか (에-고와 다이죠-부데스카) [정중체] — 영어 괜찮으세요?

**가게·식당**
- これを ください (코레오 쿠다사이) [정중체]
- ~を おねがいします (~오 오네가이시마스) [정중체]
- いくらですか (이쿠라데스카) [정중체] → 반말 いくら?
- カードで いいですか (카-도데 이-데스카) [정중체]
- おかいけい おねがいします (오카이케- 오네가이시마스) [정중체] — 계산할게요.

**길·교통**
- トイレは どこですか (토이레와 도코데스카) [정중체] → 반말 トイレ どこ?
- ~まで おねがいします (~마데 오네가이시마스) [정중체] — 택시에서
- ~えきは どこですか (~에키와 도코데스카) [정중체]

**업무 맛보기**
- ~と もうします (~토 모-시마스) [비즈니스 경어] → 정중체 ~です
- おせわに なっております (오세와니 낫테 오리마스) [비즈니스 경어] → 정중체 こんにちは
- よろしく おねがいいたします (요로시쿠 오네가이 이타시마스) [비즈니스 경어] → 정중체 よろしく おねがいします
- おつかれさまです (오츠카레사마데스) [정중체] → 반말 おつかれ
