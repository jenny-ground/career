학원 원장(Claude Code)이 매주 이 파일을 기준으로 학생의 진도를 점검하고 다음 주 수업을 짠다.

## 학생

- 완전 초보: 예전에 배웠지만 5년 넘게 쉬었고, 히라가나도 잘 못 읽는다.
- 목적: 여행, 업무, JLPT. 하루 15~20분, 휴대폰, 주 5회.
- 난이도는 학생이 채팅에서 조정한다(`더 쉽게` / `더 어렵게`). 원장은 그 메모를 보고 다음 주 계획에 반영한다.
- 한국 한자를 배운 적이 있다. 한자는 매일 회사 책상에서 수업 노트로 따로 공부하고, 선생님이 수업 끝에 읽기를 점검한다.

## 1년 로드맵

기간은 예상치다. 매주 점검 결과에 따라 늘이거나 줄인다. **진급 기준**을 넘어야 다음 단계로 간다.

### 1단계 · 가나 읽기 + 인사·자기소개 (약 6주, 2026년 11월~12월)
- 목표: 히라가나와 가타카나를 읽고, 인사와 간단한 자기소개를 한다.
- 수업: 수업 은행 P1 (1~2주 히라가나, 3~4주 가타카나와 섞어 읽기, 5~6주 인사·자기소개 실전과 한자 첫걸음)
- 진급 기준
  - 히라가나(탁음·요음 포함) 무작위 20자를 한 글자 3초 안에 읽는다(18자 이상).
  - 가타카나 외래어 10개(メニュー, ホテル 등)를 읽고 뜻을 말한다(8개 이상).
  - 30초 자기소개(인사·이름·나라·직업·취미·마무리)를 보지 않고 말한다.
  - 휴대폰 일본어 자판으로 자기소개 3문장을 가나로 쓴다.
  - 배운 한자 무작위 10자를 보고 일본어 읽기와 뜻을 말한다(8자 이상).

### 2단계 · 기초 문형 (약 10주, 2026년 12월 말~2027년 2월)
- 목표: です・ます와 기본 조사로 짧은 문장을 만들고, 숫자·시간·날짜를 듣고 말한다.
- 수업: 수업 은행 P2 (です・ます, こそあど, は・が・を・に・で, 동사 ます형, 숫자·가격, 시간·요일·날짜, 형용사, ました・ませんか)
- 진급 기준
  - 숫자·가격·시간·날짜 10개를 듣고 받아 적는다(8개 이상).
  - 하루 일과를 ます형으로 5문장 말한다.
  - 가나 입력으로 3문장 메시지를 10분 안에 쓴다(첨삭 3개 이하).
  - 배운 한자 무작위 20자를 보고 읽기와 뜻을 말한다(16자 이상).

### 3단계 · 생활 회화 (약 12주, 2027년 3월~5월) → JLPT N5 수준
- 목표: 여행과 일상에서 필요한 대화를 혼자 해낸다.
- 주제: 쇼핑, 음식점 주문·계산, 교통(전철·택시·길 묻기), 호텔, 여행 계획, 취미 이야기, N5 문제 맛보기 (한자 트랙 계속, 누적 약 270자)
- 진급 기준
  - 음식점에서 입장 → 주문 → 계산까지 롤플레이를 한국어 없이 끝낸다.
  - 길 묻기 롤플레이에서 다시 묻는 표현을 써서 목적지를 알아낸다.
  - JLPT N5 모의 문제(문자·어휘·문법·청해 각 10문항)에서 60% 이상.

### 4단계 · 이어지는 말하기 (약 12주, 2027년 6월~8월) → JLPT N4 수준
- 목표: 문장을 이어서 경험·이유·희망을 말한다.
- 주제: て형(~て ください, ~て います), 보통체와 과거형(た형), 이유 말하기(~から, ~ので), 희망(~たい), 의견(~と おもいます), 경험(~た ことが あります) (한자 트랙 계속, 누적 약 390자 · N4 범위 포함)
- 진급 기준
  - 지난 주말에 한 일을 1분 동안 과거형으로 말한다.
  - 이유를 붙여 의견을 말하는 3분 대화를 한다.
  - JLPT N4 모의 문제에서 60% 이상.

### 5단계 · 목적에 맞춘 심화 (약 12주, 2027년 9월~11월)
- 목표: 학생의 세 가지 목적(여행·업무·시험) 중 그 시기에 가장 필요한 것에 집중한다. 비중은 4단계가 끝날 때 원장이 학생에게 묻고 정한다.
- 갈래
  - **여행 실전**: 여행 일정 직접 짜기, 예약 전화·메일, 문제 생겼을 때(분실·변경), 현지 안내문 읽기
  - **업무**: 비즈니스 경어(존경어·겸양어), 업무 자기소개, 메일 기본 형식(お世話になっております), 전화 응대, 물류 기본 용어
  - **JLPT N3 준비**: 기출 유형 연습, 한자·어휘 확장, 독해·청해 시간 재기
- 기준은 4단계가 끝날 때 원장이 학생 상태와 목적을 보고 정한다.

### 1년 이후 · 유지와 심화
- 목적 중심 주 3회 수업 + 분기별 레벨 점검. JLPT 응시 일정이 있으면 그에 맞춰 역산한다.

## 매주 수업 구성

- **새 수업 N개 + 대화의 날 1회.** 대화의 날은 항상 그 주의 마지막 수업이다. 그 주에 배운 표현만으로 유키와 8~12번 주고받고, 끝나면 한국어로 피드백한다.
- **진도보다 기억이 먼저.** 핵심 표현은 다른 날 3번 연속 맞혀야 '숙달'이다. 숙달 전까지는 새 수업을 나가지 않는 날에도 복습에 계속 나온다. 가나 글자도 행 단위(예: "あ행 5자")로 핵심 표현처럼 숙달을 추적한다.
- **표기 단계** (선생님 지침 4번 표기 규칙)
  - 1~4주차 (2026-W46 ~ W49): 모든 일본어에 히라가나 읽기 + 한국어 발음
  - 5주차부터 (2026-W50 ~): 한국어 발음 없음, 한자에만 후리가나
- **읽기 단계**: 글자 → 단어 → 짧은 문장. 1~2주차 히라가나, 3~4주차 가타카나와 섞어 읽기, 5주차부터 짧은 글(문장 수는 주간 계획에 적는다).
- **쓰기 단계**: 1~2주차 로마자 입력 OK → 3주차부터 휴대폰 일본어 자판으로 가나 입력.
- **듣기**: 음성 모드에서 아주 천천히, 같은 문장을 두 번 말한다.
- **한자 트랙**: 2026-W46 수업1부터 수업마다 한자 2자(수업1 한자 家·駅은 수업 노트에 나중에 추가)(주 약 8~10자). 순서는 `lesson-bank.md`의 "한자 순서"를 따르고, 이미 배운 단어에 나오는 한자부터 한다. 수업 노트에 일본 한자와 한국 한자(훈음·모양 비교)를 같이 적는다. 학생은 책상에서 노트로 공부하고, 선생님은 매 수업 끝에 읽기를 점검한다.
  - 목표 누적: 1단계 끝 약 45자 → 2단계 끝 약 145자(JLPT N5 약 100자 포함) → 3단계 끝 약 270자 → 4단계 끝 약 390자(N4 약 300자 포함)

## 주간 점검 규칙 (매주 일요일 저녁)

### 1. 읽을 것
- 노션 **수업 기록**: 지난 7일치
- 노션 **핵심 표현**: 전체 (학습중 개수, 숙달 개수, 2주 넘게 학습중인 것, 가나 행별 숙달 현황, 한자 학습중·숙달 수)
- 노션 **이번 주 수업 계획**: 계획한 수업 수, 기본 시간
- 이 파일과 `lesson-bank.md`, 지난 주차 `weekly/*.md`

### 2. 계산할 것
- **완료율** = 상태 "완료" 수업 수 ÷ 계획한 수업 수 ("일부"는 0.5개)
- **주된 결석 이유**: "못함·일부" 기록의 못한 이유 중 가장 많은 것
- **평균 난이도**(1~5), **분량** 응답 중 가장 많은 것
- **반복 실수**: 실수 노트에 2번 이상 나온 것 (헷갈리는 가나 글자 포함)
- **기억 상태**: 학습중 핵심 표현 수, 이번 주 새로 숙달된 수, 숙달된 가나 행 수, 한자 학습중·숙달 수와 점검 정답률, 대화의 날 점수 3개

### 3. 조정 규칙
| 상황 | 다음 주 조정 |
|---|---|
| 기록이 하나도 없음 | **재시작 주간**: 수업 3개, 15분 기본, 지난주 수업 반복. 첫 수업에서 선생님이 이유를 묻도록 계획에 적는다 |
| 완료율 < 50%, 이유 "양이 많음" | 수업 수 −1 (최소 3개) 또는 기본 시간 한 단계 축소(30→20→15분). 진도 유지 |
| 완료율 < 50%, 이유 "시간 없음" | 기본 15분, 주 3~4회. 짬 날 때 하기 좋게 롤플레이 비중을 높인다 |
| 완료율 < 50%, 이유 "어려움" | 진도 멈춤. 같은 주제를 쉬운 버전으로 다시(새 글자·단어 절반, 롤플레이 대본 제공, 핵심 표현 2개) |
| 완료율 50~80% | 진도 유지. 못한 수업을 다음 주 앞에 이월 |
| 완료율 ≥ 80%, 난이도 ≤ 2, 분량 "적음" | 진도 가속: 수업 +1 또는 읽기 길이 +20%, 롤플레이 시간 늘림 |
| 완료율 ≥ 80%, 난이도 ≥ 4 | 진도 유지, 복습 비중 높임(복습 표현 6개로) |
| 반복 실수 | 다음 주 복습 표현에 고정, 쓰기 과제에 일부러 넣음 |
| 학습중 핵심 표현 10개 이상 | 새 수업 −1, 그 자리를 복습 수업으로. 진도보다 기억 우선 |
| 2주 넘게 숙달 안 된 핵심 표현 | 다음 주 쓰기 과제와 대화의 날 상황에 반드시 넣음 |
| 학습중 한자 10자 이상 | 다음 주 새 한자를 수업마다 1자로 줄이고 점검을 늘림 |
| 한자 점검 정답률 ≥ 80%, 학습중 한자 5자 이하 | 다음 주 새 한자를 수업마다 3자로 늘림 |
| 대화의 날 "대화 이어가기" 점수 ≤ 2 | 다음 주 롤플레이 시간 늘리고 대본 먼저 보여주기 |
| 기록 메모에 "더 쉽게"·"더 어렵게" 요청 | 다음 주 기본 양·속도를 그 방향으로 한 단계 조정 |
| 기록 메모에 여행·시험 일정 | 그 주는 `여행 준비` 수업이나 시험 대비 수업을 먼저 넣음 |
| 4주마다 | 마지막 수업을 **미니 레벨 점검**으로 바꿈(현재 단계 진급 기준으로 테스트) |
| 진급 기준 통과 | 다음 단계로 이동, 로드맵 기간 수정 |

### 4. 쓸 것
1. 노션 **주간 리포트** 하위 페이지: `주간 리포트 · 2026-W46` (완료율, 결석 이유, 난이도, 잘한 점, 반복 실수, 핵심 표현·가나·한자 숙달 현황, 대화의 날 점수, 조정 내용과 이유)
2. 노션 **이번 주 수업 계획** 페이지를 다음 주 계획으로 교체
3. GitHub `japanese/academy/weekly/<주차>.md`에 같은 계획 저장, 로드맵 기간이 바뀌면 이 파일도 수정
4. 학생에게 3줄 요약: 지난주 결과, 바뀐 점, 이번 주 첫 수업
