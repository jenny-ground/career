# 일본어 과외 학원 (여행·업무·JLPT, 완전 초보부터)

Claude 채팅의 **과외 선생님**이 매일 1:1 수업을 하고, Claude Code **학원 원장**이 매주 진도를 점검해서 다음 주 수업을 조정한다.

| 파일 | 내용 |
|---|---|
| `claude-teacher.md` | 과외 선생님 지침 원본. 노션 "선생님 지침"이 이 파일의 사본이다 |
| `academy/roadmap.md` | 1년 로드맵(가나 → 기초 문형 → N5 생활 회화 → N4 → 목적 심화), 단계별 진급 기준, 주간 점검·조정 규칙 |
| `academy/lesson-bank.md` | 수업 은행 (1~2단계 54개 수업 + 한자 순서 + 여행·생활 생존 표현) |
| `academy/pattern-bank.md` | 기초 회화 패턴 은행 (자주 쓰는 대화 패턴 30개, 반말 형태와 일상·실전 예문) |
| `academy/weekly/` | 주차별 수업 계획 보관 |

## 매일 수업 듣는 법
Claude 앱(폰·컴퓨터 같은 계정) → 프로젝트 "일본어 스터디" → 새 대화 → `수업 시작`

바쁜 날은 `오늘 5분만`(패턴 드릴만), 더 하고 싶으면 `수업 더`.

## 원장 점검 일정
- 매주 일요일 21:13: 주간 점검(주간 리포트, 다음 주 계획)
- 이틀마다 21:47: 중간 점검(`[피드백]` 표시와 최근 수업을 보고 지침·이번 주 계획을 바로 고침)

## 규칙이 연결되는 방식
- 프로젝트 **지침**에는 짧은 시작 문장만 있다: 노션 "선생님 지침" 페이지를 읽고 따르라는 내용.
- 노션 "선생님 지침"(https://www.notion.so/412637545a6d8193b29ffdec4d48c2ff)은 `claude-teacher.md`의 사본이다. 원장이 이 파일을 고치면 노션 사본도 같이 고친다.
- 그래서 규칙을 바꿔도 프로젝트 지침은 다시 붙여넣을 필요가 없다.

## 일본어 학원만의 규칙
- 1~4주차는 모든 일본어에 히라가나 읽기와 한국어 발음을 붙이고, 5주차부터는 한자에 후리가나만 단다.
- 쓰임새 표시: [정중체] / [반말] / [비즈니스 경어] / [정중체·반말]. 한쪽을 배우면 다른 말투도 같이 배운다.
- 가나 글자도 핵심 표현처럼 행 단위로 숙달을 추적한다.
- 롤플레이·대화의 날 상대는 일본인 친구 유키(가상 인물, 원래 친구)다. 처음 만나는 장면은 유키의 친구 켄이 맡는다.
- 패턴 먼저: 자주 쓰는 대화 패턴을 쉬운 문장으로 입에 붙인 뒤 여행·업무 단어만 바꿔 끼운다(주 구성: 패턴 수업 3 + 실전 수업 1 + 대화의 날).
