# 수업 은행 (Lesson Bank)

원장이 매주 **이번 주 수업 계획**을 만들 때 여기서 수업을 꺼내 쓴다. 학생 상태에 맞게 순서를 바꾸거나, 쉬운 버전으로 쪼개거나, 같은 수업을 다시 넣어도 된다.

- 수업 번호: `P1-01`처럼 단계(Phase)와 순서로 부른다. P1 = 1단계(화물 컨콜·메일 생존), P2 = 2단계(TMS 업무 설명·협의).
- 3단계 이후 수업은 로드맵(`roadmap.md`)의 주제를 보고 원장이 그 시기에 새로 만들어 여기에 추가한다.
- 각 수업: **주제 / 핵심 표현 / 읽기 / 쓰기 / 롤플레이**

### P1 · 1묶음 · 컨콜 생존과 일정
- **P1-01 · 회의 일정 잡기** / I'd like to schedule a meeting. · Are you available next Tuesday? · What time works for you? / 읽기: 협력사의 회의 요청 메일 / 쓰기: "다음 주 화요일에 TMS 요구사항 관련 회의를 하고 싶습니다." / 롤플레이: 전화로 회의 시간 정하기
- **P1-02 · 통화 시작하고 다시 묻기** / Can you hear me okay? · Sorry, could you repeat the last part? · Sorry, you're breaking up. / 읽기: 컨콜 초대 메일(시간, 링크, 안건) / 쓰기: "죄송한데, 마지막 부분을 다시 말씀해 주시겠어요? 픽업 시간을 잘 못 들었어요." / 롤플레이: 컨콜 첫 1분, 잘 안 들려서 다시 묻기
- **P1-03 · 도착 시간과 일정 확인** / Just to confirm, ~, right? · What is the ETA for this shipment? · The truck is running two hours late. / 읽기: 배송 지연 안내 메일 / 쓰기: "확인차 여쭤보면, 도착 예정 시간이 금요일 오후 3시 맞죠? 통화 끝나고 메일로 보내주실 수 있나요?" / 롤플레이: ETA 문의 전화
- **P1-04 · 컨콜 마무리** / Let me summarize the next steps. · We will share ~ by Wednesday. · Talk to you on Tuesday. / 읽기: 짧은 회의 요약 메일 / 쓰기: "오늘 참석해 주셔서 감사합니다. 저희는 수요일까지 화면 설계를 공유드리겠습니다. 다음 주 화요일에 이야기 나눠요." / 롤플레이: 회의 끝내기
- **P1-05 · 운송 상태 말하기** / The shipment was delivered this morning. · We haven't received the POD yet. · The carrier changed the pickup time. / 읽기: 화물 상태 업데이트 메일 / 쓰기: "그 화물은 오늘 아침에 배송됐지만, 아직 POD를 못 받았어요. 확인하고 다시 알려드릴게요." / 롤플레이: 주간 화물 상태 공유

### P1 · 2묶음 · 내 소개와 운송 기본 용어
- **P1-06 · 자기소개와 역할** / I'm in charge of ~. · My team handles ~. · I'll be your main contact for ~. / 읽기: 상대 팀 소개 메일 / 쓰기: 3문장 자기소개 메일 / 롤플레이: 첫 미팅 자기소개
- **P1-07 · 화주·수하인·운송사** / Who is the consignee? · Which carrier do you use? · The shipper is ~. / 읽기: 운송 지시 요약 / 쓰기: 운송 정보 요청 2문장 / 롤플레이: 새 운송 구간(lane) 정보 묻기
- **P1-08 · 숫자, 날짜, 시간** / on Friday, November 14 · at 3:30 p.m. Central Time · 12 pallets, 20 tons / 읽기: 픽업 일정표 / 쓰기: 일정 확인 메일 / 롤플레이: Mike가 말하는 숫자 받아 적기(듣기 집중)
- **P1-09 · 운임과 비용** / What is the freight rate for ~? · Does the rate include ~? · There is a fuel surcharge. / 읽기: 운임 변경 안내 메일 / 쓰기: 비용 질문 메일 / 롤플레이: 운임 문의
- **P1-10 · 의견 말하기 + 2주 복습** / I think ~. · I have a concern about ~. · What do you think? / 읽기: 개선 제안 메일 / 쓰기: 내 의견 2문장 / 롤플레이: 1–2주 표현을 섞은 5분 미니 컨콜

### P1 · 3묶음 · 메일 쓰기 1
- **P1-11 · 메일 기본 구조** / Subject · Hi ~, · Best regards / 읽기: 잘 쓴 메일과 어색한 메일 비교 / 쓰기: 짧은 메일 한 통(제목부터 서명까지) / 롤플레이: 메일 내용을 전화로 다시 설명하기
- **P1-12 · 요청하기** / Could you ~? · Would it be possible to ~? · by Friday / 읽기: 자료 요청 메일 / 쓰기: 운송 데이터 요청 메일 / 롤플레이: 전화로 요청하고 메일로 보내겠다고 말하기
- **P1-13 · 첨부와 공유** / Please find ~ attached. · I've shared the file with you. · Let me know if you can't open it. / 읽기: 파일 공유 메일 / 쓰기: 화면 설계서 첨부 메일 / 롤플레이: 파일이 안 열린다는 문의 응대
- **P1-14 · 감사·사과** / Thank you for your quick reply. · Sorry for the late reply. · I apologize for the confusion. / 읽기: 사과 메일 / 쓰기: 늦은 답장 사과 + 답변 / 롤플레이: 실수 사과하기
- **P1-15 · 일정 변경** / Can we move the meeting to ~? · Something came up. · Does ~ work instead? / 읽기: 일정 변경 요청 메일 / 쓰기: 회의 시간 변경 요청 메일 / 롤플레이: 전화로 일정 바꾸기

### P1 · 4묶음 · 메일 쓰기 2
- **P1-16 · 확인 메일** / I'd like to confirm ~. · Please correct me if I'm wrong. · Did you mean ~? / 읽기: 확인 요청 메일 / 쓰기: 컨콜에서 들은 내용 확인 메일 / 롤플레이: 헷갈린 내용 다시 확인
- **P1-17 · 회의 후 요약 메일** / Here is a summary of today's call. · Action items · Next steps / 읽기: 요약 메일 예시 / 쓰기: 합의 2개 + 할 일 2개 요약 메일 / 롤플레이: 회의 마지막 2분
- **P1-18 · 후속 확인과 리마인드** / Just a quick reminder. · I'm following up on ~. · Could you let me know the status? / 읽기: 리마인드 메일 / 쓰기: 답이 없는 자료 요청 다시 보내기 / 롤플레이: 진행 상황 묻기
- **P1-19 · 문제 알리기** / I'm writing to let you know ~. · Unfortunately, ~. · We are working on it. / 읽기: 시스템 장애 안내 메일 / 쓰기: 배차 화면 오류 안내 메일 / 롤플레이: 문제를 전화로 알리기
- **P1-20 · 4주 복습** / 1–4주 메일 표현 / 읽기: 실제와 비슷한 긴 메일 / 쓰기: 메일 한 통 처음부터 끝까지 / 롤플레이: 메일 내용으로 5분 컨콜

### P2 · 1묶음 · 업무 설명 1 (TMS와 배차)
- **P2-01 · 우리 TMS 소개** / Our TMS manages ~. · It covers everything from orders to settlement. · Our users are ~. / 읽기: TMS 소개 글 / 쓰기: 우리 시스템 소개 3문장 / 롤플레이: 1분 시스템 소개
- **P2-02 · 배차 흐름** / First, ~. Then, ~. After that, ~. Finally, ~. / 읽기: 배차 프로세스 설명 / 쓰기: 배차 흐름 4단계 / 롤플레이: 배차 흐름 설명하고 질문 받기
- **P2-03 · 화면 공유하며 설명** / Let me share my screen. · On the left, you can see ~. · If you click this button, ~. / 읽기: 화면 설명서 일부 / 쓰기: 화면 하나 설명 3문장 / 롤플레이: 화면 공유 데모
- **P2-04 · 기능 설명** / This feature allows you to ~. · Users can ~. · It is useful when ~. / 읽기: 기능 릴리스 노트 / 쓰기: 기능 하나 소개 / 롤플레이: 새 기능 설명
- **P2-05 · 질문 받고 답하기** / That's a good question. · Let me explain. · I'll check and get back to you. / 읽기: 질문 목록 메일 / 쓰기: 질문 2개에 답하기 / 롤플레이: Mike의 예상 못한 질문에 답하기

### P2 · 2묶음 · 업무 설명 2 (추적·정산·연동)
- **P2-06 · 화물 추적** / real-time tracking · status update · We send an alert when ~. / 읽기: 추적 기능 설명 / 쓰기: 추적 상태 설명 / 롤플레이: 추적 기능 데모
- **P2-07 · 정산 흐름** / invoice · approve · Settlement is done at the end of each month. / 읽기: 정산 절차 안내 / 쓰기: 정산 흐름 3단계 / 롤플레이: 정산 일정 문의 응대
- **P2-08 · 시스템 연동** / integration · API · What data format do you use? / 읽기: 연동 요청 메일 / 쓰기: 연동 관련 질문 메일 / 롤플레이: 연동 방식 논의
- **P2-09 · 비교와 장단점** / Compared to ~, ~. · The advantage is ~. · The downside is ~. / 읽기: 두 방안 비교 메일 / 쓰기: 방안 A·B 비교 3문장 / 롤플레이: 어떤 방안이 좋은지 논의
- **P2-10 · 6주 복습** / 5–6주 설명 표현 / 읽기: 프로젝트 현황 메일 / 쓰기: 배차부터 정산까지 5문장 / 롤플레이: 2분 발표 후 질문 받기

### P2 · 3묶음 · 요구사항 협의와 일정 조율
- **P2-11 · 요구사항 듣고 정리** / So you need ~, right? · Is that a must-have? · Could you give me an example? / 읽기: 요구사항 목록 메일 / 쓰기: 들은 요구사항 정리 / 롤플레이: 요구사항 인터뷰
- **P2-12 · 범위 협의** / This is in scope. · That's out of scope for phase one. · We can consider it later. / 읽기: 범위 정의 메일 / 쓰기: 범위 밖 요청 정중히 답하기 / 롤플레이: 추가 요청 협상
- **P2-13 · 일정 조율** / The deadline is tight. · Can we extend ~? · We can deliver ~ by ~ if ~. / 읽기: 일정 변경 요청 / 쓰기: 일정 연장 요청 메일 / 롤플레이: 마감 협상
- **P2-14 · 정중하게 반대하기** / I see your point, but ~. · That might be difficult because ~. · We could ~ instead. / 읽기: 제안 메일 / 쓰기: 대안 제시 메일 / 롤플레이: 반대 의견 말하기
- **P2-15 · 결정 확인** / So we agreed that ~. · Who will ~? · By when? / 읽기: 합의 메일 / 쓰기: 결정 사항 확인 메일 / 롤플레이: 회의 결론 정리

### P2 · 4묶음 · 이슈 대응과 실전
- **P2-16 · 이슈 보고** / We found an issue in ~. · The impact is ~. · The workaround is ~. / 읽기: 이슈 리포트 / 쓰기: 이슈 보고 메일 / 롤플레이: 긴급 이슈 통화
- **P2-17 · 원인과 해결** / The cause was ~. · We fixed ~. · It will be deployed on ~. / 읽기: 장애 원인 분석 메일 / 쓰기: 해결 안내 메일 / 롤플레이: 원인 설명하고 질문 받기
- **P2-18 · 테스트와 오픈 준비** / UAT will start on ~. · Please test ~. · We are ready for go-live. / 읽기: UAT 안내 메일 / 쓰기: 테스트 요청 메일 / 롤플레이: 오픈 준비 점검 회의
- **P2-19 · 실전 컨콜** / 지금까지의 모든 표현 / 읽기: 실제 같은 회의 안건 / 쓰기: 회의 후 요약 메일 / 롤플레이: 15분 실전 컨콜(시작→안건 2개→마무리)
- **P2-20 · 총복습** / 내가 자주 틀린 표현 / 읽기: 8주 동안 나온 메일 중 하나 / 쓰기: 자유 메일 / 롤플레이: 자유 대화 후 레벨 점검과 다음 8주 제안

8주가 끝나면 학습자의 약한 영역을 기준으로 다음 8주 계획을 제안한다.

## 부록 · 컨콜 생존 표현 (복습용)

복습 단계에서 매일 2개씩 골라 묻는다.

**통화 시작**
- Hi everyone, can you hear me? [대화] → 메일에선 Please let me know if you have trouble joining the call.
- Thank you for joining. [대화·메일]
- Shall we get started? [대화]
- Can you see my screen? [대화]

**못 알아들었을 때**
- Sorry, could you say that again? [대화]
- Could you speak a little more slowly, please? [대화]
- Sorry, the line is not very clear. [대화]
- Sorry, I'm not sure I understand. [대화] → 메일에선 I'm not sure I understood correctly.

**확인할 때**
- Just to confirm, you mean the pickup time, right? [대화] → 메일에선 Just to confirm, do you mean the pickup time?
- So the deadline is next Friday, correct? [대화] → 메일에선 Could you confirm that the deadline is next Friday?
- Could you send that by email after the call? [대화]
- Could you share the file? [대화·메일]

**생각할 시간이 필요할 때**
- Give me a second, please. [대화]
- Let me check and get back to you. [대화·메일]
- Can we discuss this internally first? [대화] → 메일에선 We would like to discuss this internally first.

**의견**
- I think that works for us. [대화·메일]
- I have a concern about the schedule. [대화·메일]
- Do you have any questions? [대화·메일]
- Let me share my screen. [대화]

**마무리**
- Let me summarize what we agreed. [대화] → 메일에선 Here is a summary of what we agreed.
- I'll send a follow-up email today. [대화]
- Thank you for your time. Talk to you next week. [대화] → 메일에선 I look forward to our next meeting.

**메일 전용**
- Please find the file attached. [메일] → 말할 땐 I'll send you the file.
- Please let me know if you have any questions. [메일] → 말할 땐 Any questions?
- Sorry for the late reply. [메일] → 말할 땐 Sorry I didn't get back to you sooner.
- I look forward to hearing from you. [메일] → 말할 땐 Talk to you soon.
