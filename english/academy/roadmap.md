## 1년 로드맵

기간은 예상치다. 매주 점검 결과에 따라 늘이거나 줄인다. **진급 기준**을 넘어야 다음 단계로 간다.

### 1단계 · 기초 패턴 + 화물 컨콜 생존 (약 10주, 2026년 11월~2027년 1월)
- 목표: 기초 회화 패턴 30개를 입에 붙이고, 그 패턴으로 카길 컨콜에서 버티고 짧은 업무 메일을 쓴다.
- **재구성 (2026-11-14, 학생 상담)**: 학생이 "일상 회화가 안 되니 업무 문장이 입에 안 붙는다, We'll go over 같은 틀이 익숙하지 않아 매번 기억이 안 난다"고 했다. 그래서 1단계를 **패턴 트랙 중심**으로 바꾼다. 업무 문장은 패턴 + 업무 단어로 가르치고, 새 업무 수업은 이미 배운 패턴으로만 된 문장을 쓴다.
- 패턴: `pattern-bank.md` 묶음 1~6 (30개). 처음 2주는 패턴 수업 1회당 1개, 쉬워하면 2개.
- 수업: 수업 은행 P1 (컨콜 시작·마무리, 다시 묻기, 일정·ETA 확인, 운송 용어, 숫자·날짜, 운임, 메일 기본·요청·첨부·사과·일정 변경, 확인·요약·리마인드·문제 알림 메일)
- 진급 기준
  - 패턴 30개 중 25개 숙달(처음 보는 문장을 그 패턴으로 3초 안에 말하기).
  - 컨콜 생존 표현 20개를 한국어를 보고 3초 안에 영어로 말한다.
  - 3~5문장 업무 메일을 번역기 없이 15분 안에 쓴다(첨삭 3개 이하).
  - 5분 롤플레이에서 못 알아들었을 때 다시 묻는 표현을 자연스럽게 쓴다.

### 2단계 · TMS 업무 설명과 협의 (약 8주, 2027년 1월~2월)
- 목표: 우리 시스템과 업무 흐름을 영어로 설명하고, 요구사항과 일정을 협의한다.
- 수업: 수업 은행 P2 (TMS 소개, 배차·추적·정산·연동 설명, 화면 공유 데모, 질문 응대, 요구사항 정리, 범위·일정 협의, 이슈 보고, UAT·오픈)
- 진급 기준
  - 배차부터 정산까지 2분 동안 설명한다.
  - 10분 요구사항 협의 롤플레이를 한국어 없이 끝낸다.
  - 회의 후 요약 메일(합의·할 일 포함)을 20분 안에 쓴다.

### 3단계 · 비즈니스 영어 기본기 확장 (약 12주, 2027년 3월~5월)
- 목표: 화물 업무 밖의 일반 비즈니스 상황에서도 대화를 이어간다.
- 주제: 회의 진행하기, 숫자·데이터·그래프 설명, 스몰토크와 관계 쌓기, 화상회의 매너, 자주 틀리는 문법 보강(시제, 관사, 전치사), 실제 속도 영상 듣기
- 진급 기준
  - 1분 즉흥 스몰토크를 한다.
  - 15분 회의 진행 롤플레이(안건 소개 → 의견 묻기 → 정리)를 한다.
  - 실제 속도 비즈니스 영상(3분)의 요점을 60% 이상 이해한다.

### 4단계 · 협상·설득·문서 (약 12주, 2027년 6월~8월)
- 목표: 이견을 조율하고, 영어 문서와 발표를 만든다.
- 주제: 협상과 양보, 정중하게 반대하기, 제안서·요구사항 정의서 영어 작성, 5분 발표와 질의응답, 메일 톤 조절(정중·단호)
- 진급 기준
  - 5분 발표 후 질문 3개에 답한다.
  - 1페이지 영문 업무 문서를 쓴다.

### 5단계 · 고도화 (약 12주, 2027년 9월~11월)
- 목표: 자연스러운 속도로 듣고 즉흥적으로 대응한다.
- 주제: 원어민 속도 듣기, 돌발 질문 대응, 미국 비즈니스 문화, 어려운 소식 전하기, 리더십 표현, 실제 업무 자료로 수업
- 기준은 4단계가 끝날 때 원장이 학생 상태를 보고 정한다.

### 1년 이후 · 유지와 심화
- 실제 업무 자료(메일, 회의록) 기반 주 3회 수업 + 분기별 레벨 점검.

## 매주 수업 구성

- **1단계 동안 주 구성: 패턴 수업 3개 + 업무 수업 1개 + 대화의 날 1회.** 업무 수업은 그 주 패턴이 들어간 수업 은행 수업을 고르고, 패턴 + 업무 단어로 설명한다. 바쁜 주에는 패턴 수업을 5분 드릴로 해도 된다(완료로 센다).
- **새 수업 N개 + 대화의 날 1회.** 대화의 날은 항상 그 주의 마지막 수업이다. 그 주에 배운 표현만으로 Mike와 8~12번 주고받고, 끝나면 한국어로 피드백한다.
- **진도보다 기억이 먼저.** 핵심 표현은 다른 날 3번 연속 맞혀야 '숙달'이다. 숙달 전까지는 새 수업을 나가지 않는 날에도 복습에 계속 나온다. 수업당 핵심 표현은 기본 3개다(학생 요청, 2026-11-09).
- **예비 수업 2개.** 학생은 원할 때 하루에 여러 수업을 들을 수 있다. 계획 수업을 다 하면 예비 수업을 하고, 그것도 다 하면 복습 수업을 한다.
- **깜짝 복습(매주 수요일).** 숙달 표현 3개를 예고 없이 묻고, 틀리면 다시 '학습중'으로 돌린다.

## 주간 점검 규칙 (매주 일요일 저녁)

### 1. 읽을 것
- 노션 **수업 기록**: 지난 7일치
- 노션 **핵심 표현**: 전체 (학습중 개수, 숙달 개수, 2주 넘게 학습중인 것)
- 노션 **이번 주 수업 계획**: 계획한 수업 수, 기본 시간
- 이 파일과 `lesson-bank.md`, 지난 주차 `weekly/*.md`

### 2. 계산할 것
- **완료율** = 상태 "완료" 수업 수 ÷ 계획한 수업 수 ("일부"는 0.5개)
- **주된 결석 이유**: "못함·일부" 기록의 못한 이유 중 가장 많은 것
- **평균 난이도**(1~5), **분량** 응답 중 가장 많은 것
- **반복 실수**: 실수 노트에 2번 이상 나온 것
- **기억 상태**: 학습중 핵심 표현 수, 이번 주 새로 숙달된 수, 깜짝 복습 결과(맞힘/틀려서 되돌림), 대화의 날 점수 3개
- **추가 수업**: 메모에 "추가 수업"이 있는 기록 수, 예비 수업을 몇 개 썼는지

### 3. 조정 규칙
| 상황 | 다음 주 조정 |
|---|---|
| 기록이 하나도 없음 | **재시작 주간**: 수업 3개, 15분 기본, 지난주 수업 반복. 첫 수업에서 선생님이 이유를 묻도록 계획에 적는다 |
| 완료율 < 50%, 이유 "양이 많음" | 수업 수 −1 (최소 3개) 또는 기본 시간 한 단계 축소(30→20→15분), 수업당 핵심 표현 2개(나머지는 참고 표현). 진도 유지 |
| 완료율 < 50%, 이유 "시간 없음" | 기본 15분, 주 3~4회. 출퇴근용으로 롤플레이 비중을 높인다 |
| 완료율 < 50%, 이유 "어려움" | 진도 멈춤. 같은 주제를 쉬운 버전으로 다시(읽기 −30%, 롤플레이 대본 제공, 핵심 표현 2개) |
| 완료율 50~80% | 진도 유지. 못한 수업을 다음 주 앞에 이월 |
| 완료율 ≥ 80%, 난이도 ≤ 2, 분량 "적음" | 진도 가속: 수업 +1 또는 읽기 길이 +20%, 롤플레이 시간 늘림 |
| 완료율 ≥ 80%, 난이도 ≥ 4 | 진도 유지, 복습 비중 높임(복습 표현 6개로) |
| 반복 실수 | 다음 주 복습 표현에 고정, 쓰기 과제에 일부러 넣음 |
| 패턴 숙달이 느림(학습중 패턴 5개 이상) | 새 패턴 대신 같은 패턴을 다른 문장으로 다시 드릴 |
| 패턴을 쉽게 숙달(드릴 정답률 높음) | 패턴 수업 1회에 2개씩 |
| 예비 수업까지 다 함 | 다음 주 새 수업 +1~2, 예비 수업 3개 |
| 깜짝 복습에서 틀린 표현 | 다음 주 복습 표현과 대화의 날에 넣음 |
| 학습중 핵심 표현 10개 이상 | 새 수업 −1, 그 자리를 복습 수업으로. 진도보다 기억 우선 |
| 2주 넘게 숙달 안 된 핵심 표현 | 다음 주 쓰기 과제와 대화의 날 상황에 반드시 넣음 |
| 대화의 날 "대화 이어가기" 점수 ≤ 2 | 다음 주 롤플레이 시간 늘리고 대본 먼저 보여주기 |
| 기록 메모에 실제 컨콜 일정 | 그 주는 컨콜 준비 수업을 먼저 넣음(안건 기반) |
| 4주마다 | 마지막 수업을 **미니 레벨 점검**으로 바꿈(현재 단계 진급 기준으로 테스트) |
| 진급 기준 통과 | 다음 단계로 이동, 로드맵 기간 수정 |

### 4. 쓸 것
1. 노션 **주간 리포트** 하위 페이지: `주간 리포트 · 2026-W46` (완료율, 결석 이유, 난이도, 잘한 점, 반복 실수, 핵심 표현 숙달 현황, 대화의 날 점수, 조정 내용과 이유)
2. 노션 **이번 주 수업 계획** 페이지를 다음 주 계획으로 교체
3. GitHub `english/academy/weekly/<주차>.md`에 같은 계획 저장, 로드맵 기간이 바뀌면 이 파일도 수정
4. 학생에게 3줄 요약: 지난주 결과, 바뀐 점, 이번 주 첫 수업
