# 영어 과외 학원 (카길 컨콜 대비)

Claude 채팅의 **과외 선생님**이 매일 1:1 수업을 하고, Claude Code **학원 원장**이 매주 진도를 점검해서 다음 주 수업을 조정한다.

| 파일 | 내용 |
|---|---|
| `claude-teacher.md` | 과외 선생님 지침. Claude 채팅 프로젝트에 넣는다 |
| `academy/roadmap.md` | 1년 로드맵, 단계별 진급 기준, 주간 점검·조정 규칙 |
| `academy/lesson-bank.md` | 수업 은행 (1~2단계 40개 수업 + 컨콜 생존 표현) |
| `academy/weekly/` | 주차별 수업 계획 보관 |
| `index.html` | 표현·용어 듣기 연습 페이지 원본 |

## 매일 수업 듣는 법
Claude 앱(폰·컴퓨터 같은 계정) → 프로젝트 "영어 스터디" → 새 대화 → `수업 시작`

## 규칙이 연결되는 방식
- 프로젝트 **지침**에는 짧은 시작 문장만 있다: 노션 "선생님 지침" 페이지를 읽고 따르라는 내용.
- 노션 "선생님 지침"(https://www.notion.so/412637545a6d8182831cf1bc06ec278e)은 `claude-teacher.md`의 사본이다. 원장이 이 파일을 고치면 노션 사본도 같이 고친다.
- 그래서 규칙을 바꿔도 프로젝트 지침은 다시 붙여넣을 필요가 없다.
