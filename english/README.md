## Claude 앱에서 수업 듣는 방법

1. Claude 앱(또는 휴대폰 브라우저의 claude.ai)에서 **프로젝트**를 새로 만든다. 이름 예: `영어 선생님`
2. 프로젝트에 `claude-teacher.md`를 넣는다. 둘 중 편한 방법을 쓴다.
   - 프로젝트 지식에 **GitHub 연결** → `jenny-ground/career` → `english/claude-teacher.md` 선택
   - 또는 파일 내용을 복사해서 프로젝트 **지침(Instructions)**에 붙여넣기
3. 프로젝트 안에서 새 채팅을 열고 `Day 1 시작`이라고 보낸다.
4. 듣기·말하기 롤플레이는 채팅창의 **음성 모드**로 한다.

매일 새 채팅에서 `Day N 시작`이라고 보내면 된다. 시간이 없는 날은 `오늘 10분만`.
